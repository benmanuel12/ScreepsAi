# ScreepsAi

This is my attempt to take a basic beginner AI for Screeps and extend and update it with improvements, some neater code, and customise it for the way I prefer to play the game

Credit to https://github.com/Dragonissa/ScreepsAi for the original code

## Built with
JavaScript

## Features
- Refactored roleLib to increase flexibility of creep spawning
- Added the ability to scale up the size of creeps to match energy capacity
- Fixed some bugs

## Running it
Import into Screeps and start game
